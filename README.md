# what is creatives club?

Creatives Club is a place to ***make* and *build* things**.

Got a project idea you’ve been sitting on? Want to learn something new, build something weird, make art, code a game, design something, start a project, make music, film something, write, experiment, or just figure out how to turn an idea into reality?

That’s what this is for.

You **don’t need to already be good at anything** or even know exactly what you want to make. The goal is to have a space where people can bring ideas, learn from each other, work on projects, and actually make stuff instead of just talking about it.

It’s not really a coding club, art club, entrepreneurship club, or anything else that fits neatly into one box. It’s more about the intersection of **creativity, building, learning, and community**.

Basically:

> **“I have this idea. I want to make it.”**

…and Creatives Club is a place to start.

This server is very much a work in progress, so we’ll figure out what the club actually becomes together. For now, throw ideas around, share what you’re working on, and let’s make some stuff.

> Join us. Build something. Learn something. Ship it.
